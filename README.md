# Furniture Project

Интернет-магазин мебели и товаров для дома — pet-проект на React и TypeScript. Проект в разработке: готов лендинг и общие элементы интерфейса (шапка, корзина, мобильное меню), остальные страницы в планах. Бэкенда пока нет, все данные — моки.

## Что уже сделано

**Лендинг**

- слайдер-баннер с автопролистыванием, пагинацией и кнопками «назад/вперёд» (на мобильных кнопки скрыты);
- секция Hero, витрина категорий, блок преимуществ, промо-блок распродажи;
- слайдер новинок: прокрутка мышью, колесом, свайпом и с клавиатуры, собственный скроллбар по ширине контейнера;
- секция статей блога.

**Товары, корзина и избранное**

- карточка товара с бейджами NEW и скидки, рейтингом, старой ценой и кнопками «в корзину» и «в избранное»;
- корзина в выезжающей панели: изменение количества, удаление с анимацией, итоговая сумма;
- счётчики товаров в корзине и избранном в шапке и мобильном меню;
- корзина и избранное хранятся в `localStorage` и сохраняются после перезагрузки страницы.

**Общий интерфейс**

- промо-плашка над шапкой, закрывается с анимацией (Web Animations API);
- выезжающая панель поиска и навигации: поле поиска, меню-аккордеон, ссылки на соцсети, кнопка Sign In для гостей;
- иконка профиля ведёт в профиль или на страницу входа в зависимости от роли пользователя (запрос к серверу пока имитируется с задержкой).

**Вёрстка**

- адаптив под мобильные, планшеты и десктоп (брейкпоинты 599 / 959 / 1199 px), «резиновые» размеры через миксин `fluid-property`;
- изображения в WebP с фолбэком на PNG/JPG через `<picture>`;
- иконки собраны в SVG-спрайты (одноцветные и многоцветные);
- локальные шрифты Poppins, Inter и Space Grotesk в форматах woff2 / woff / ttf.

## Архитектура

Проект построен по методологии [Feature-Sliced Design](https://feature-sliced.design/):

```
src/
├── app/        # точка входа, роутинг, глобальные стили, провайдеры
├── pages/      # страницы: Landing, Shop
├── widgets/    # крупные блоки: Header, Hero, ProductCard, FlyoutCart, FlyoutSearch и др.
├── features/   # действия пользователя: добавить в корзину/избранное, открыть корзину/поиск/меню
├── entities/   # бизнес-сущности: cart, wishlist, product, category, blog, user
└── shared/     # UI-кит, хуки, конфиг навигации, типы, моки, SCSS-переменные и миксины
```

Импорты из `src` пишутся через алиас `@`, например `import Button from '@/shared/ui/Button'`.

## Запуск

Нужен Node.js версии 20.19+ или 22.12+.

```bash
git clone git@github.com:darina-bal/furniture-project.git
cd furniture-project
npm install
npm run dev
```

После запуска сайт откроется на `http://localhost:5173`.

### Скрипты

| Команда | Что делает |
| --- | --- |
| `npm run dev` | запускает dev-сервер |
| `npm run build` | проверяет типы и собирает проект в `dist` |
| `npm run preview` | запускает локальный просмотр собранной версии |
| `npm run lint` | проверяет код ESLint |

## Деплой

Проект развёрнут на Vercel. В `vercel.json` все запросы перенаправляются на `index.html`, чтобы клиентский роутинг работал при прямом переходе по ссылке и при обновлении страницы.
